## 1. 为什么是单文件

**没有 webpack / vite / React / 构建步骤。**

一个 `index.html`，CSS 写在 `<style>` 里，JS 写在 `<script>` 里，改完直接刷新。

好处：
- 改一行立刻能看效果，不用等编译
- 交付就是「一个文件」，不会出现「少了个依赖跑不起来」
- 界面加载零延迟（没有网络请求）

代价：
- 文件大（150 KB），编辑时要小心（见下面「常见错误清单」）
- 没有组件化，重复的 HTML 要自己抽成 JS 函数

> 如果你要做的项目界面更复杂（十几个页面、多人协作），
> 那还是该上框架。**单文件适合「一个窗口、几个页签」这种规模。**

## 2. 设计令牌

把所有视觉常量抽成 CSS 变量。改一处，全局生效。

```css
:root{
  /* ── 米白暖色调（用户明确要求：不惨白、不暗色）── */
  --bg:#f5f1e8;  --bg2:#efe9dc;
  --card:#fffdf8;              /* 卡片比背景更白一点，形成层次 */
  --card2:#f7f2e7;             /* 次级背景（悬停、内嵌块）*/
  --line:#e2d9c7;  --line2:#d6cab3;     /* 边框：常态 / 悬停 */
  --text:#3d3830;  --muted:#8a8171;  --dim:#a89e8b;

  /* 强调色（图表、状态标签用） */
  --blue:#4a7fb5;  --violet:#8b6bb5;  --teal:#3f9e8c;
  --green:#4c9a63; --yellow:#c99a2e;  --orange:#d17a3e;
  --red:#c25b50;   --pink:#c46b96;

  --r:13px;  --rs:9px;         /* 圆角：大卡片 / 小控件 */

  /* 动效曲线 */
  --ease:cubic-bezier(.22,1,.36,1);
  --ease2:cubic-bezier(.4,0,.2,1);
  --fast:cubic-bezier(.33,1,.68,1);
  --spring:cubic-bezier(.34,1.56,.64,1);
}
```

**为什么这样分颜色**：
- `--bg` → `--card` → `--card2` 是**三个层次**。
  卡片比背景亮、内嵌块比卡片暗，眼睛自然能分辨层级，不需要重边框。
- `--line` / `--line2` 只在**悬停时**加深边框 + 加阴影 —— 这是
  GitHub / Vercel 这类界面的通用手法（「静→动」的对比）。

## 3.  第一条铁律：动效曲线的正确写法

###  错误写法（这个 bug 能藏很久）

```css
--ease: var(--ease);          /* 自我引用！ */
```

**CSS 变量循环依赖 → 整条声明失效 → 所有 `transition: ... var(--ease)` 全部不生效。**

结果是：**整个站点的过渡动画都变成了「硬切」**。
因为 CSS 不报错，只是静默失效，所以很难发现 —— 只会觉得「手感有点差」。

###  正确写法

```css
--ease: cubic-bezier(.22, 1, .36, 1);
```

### 四条曲线的用途

| 变量 | 值 | 什么时候用 |
|---|---|---|
| `--ease` | `cubic-bezier(.22,1,.36,1)` | **默认**。快出慢入，有「滑」的质感。位移、缩放、展开 |
| `--ease2` | `cubic-bezier(.4,0,.2,1)` | 标准 Material 曲线。背景色、透明度这类渐变 |
| `--fast` | `cubic-bezier(.33,1,.68,1)` | **80ms 级控件反馈**（按钮悬停、边框变色）。要快要干脆 |
| `--spring` | `cubic-bezier(.34,1.56,.64,1)` | **回弹**。用于「到达/成功」类动效：Tab 指示条、Toast 弹出、图标入场 |

** 怎么选**：
- 只是变色 → `--fast`
- 有位移 → `--ease`
- 需要「手感」→ `--spring`（控制点第二个值 > 1 就会过冲回弹）

### 时长参考

| 场景 | 时长 |
|---|---|
| 按钮反馈 | 0.15s |
| 卡片悬停 | 0.16–0.18s |
| 入场动画 | 0.34–0.42s |
| 页面切换 | 0.42s |
| 骨架屏循环 | 1.2–1.3s |

**原则**：**越小的元素动得越快**。27px 的按钮用 0.42s 会显得迟钝。

## 4. 七种基础动效模式

### 4.1 悬停抬升（卡片）

```css
.card{
  transition:transform .18s var(--ease),
             box-shadow .18s var(--fast),
             border-color .18s var(--fast);
  will-change:transform;              /* 提示浏览器优化 */
}
.card:hover{
  transform:translateY(-3px) scale(1.012);
  border-color:var(--line2);
  box-shadow:var(--sh-lg);
}
.card:active{transform:translateY(-1px) scale(.995)}   /* 按下时略降 */
```

**要点**：
- **位移 + 缩放同时用**（-3px + 1.012）比只用位移更有「浮起来」的感觉
- `:active` 要**回降一点**（不是归零），形成「按下去」的反馈
- `will-change:transform` 别滥用，只给会频繁动的元素

### 4.2 左侧色条（状态指示）

```css
.card::before{
  content:"";position:absolute;left:0;top:0;bottom:0;width:3px;
  background:var(--c,var(--blue));        /* 颜色由行内 style 决定 */
  border-radius:0 2px 2px 0;
  transition:width .18s var(--ease),box-shadow .18s;
}
.card:hover::before{
  width:4px;
  box-shadow:1px 0 8px -1px var(--c,var(--blue));  /* 光晕外溢 */
}
```

**技巧**：`--c` 变量在 HTML 里用行内 style 设置：
```html
<div class="card" style="--c:var(--red)">…</div>
```
这样同一个组件能自动适配不同颜色，不用写 N 个 class。

### 4.3 分层阴影（学 GitHub Primer）

```css
--sh-xs: 0 1px 0 rgba(120,105,80,.06);
--sh-sm: 0 1px 2px rgba(120,105,80,.10), 0 1px 0 rgba(120,105,80,.05);
--sh-md: 0 3px 6px rgba(120,105,80,.10), 0 1px 2px rgba(120,105,80,.07);
--sh-lg: 0 8px 22px rgba(120,105,80,.15), 0 2px 6px rgba(120,105,80,.09);
--sh-xl: 0 16px 44px rgba(120,105,80,.20), 0 4px 12px rgba(120,105,80,.11);
```

**关键**：每层用**两个阴影叠加** ——
一个「小的紧阴影」负责锐利边缘，一个「大的散阴影」负责柔和的投影。
比单个 `0 4px 16px` 精致得多，而且因为模糊半径小，**渲染还更快**。

### 4.4 统一点击反馈

```css
button:not(:disabled):active{transform:scale(.97)}
```

**一行代码，全站按钮都有了「按下去」的手感。**
关键是**要快** —— 80ms 级，不能有过渡延迟感。

### 4.5 交错入场（stagger）

内容不要一次全出现，要**依次**浮现：

```css
@keyframes riseIn{
  from{opacity:0;transform:translateY(10px) scale(.985)}
  to  {opacity:1;transform:none}
}
.sec{animation:riseIn .38s var(--ease) both}
.sec:nth-child(1){animation-delay:0ms}
.sec:nth-child(2){animation-delay:45ms}
.sec:nth-child(3){animation-delay:90ms}
/* … */
.sec:nth-child(n+8){animation-delay:300ms}   /*  设上限！ */
```

** 两个要点**：
1. `both` 是必须的 —— 让动画开始前保持 `from` 状态（否则会闪一下）
2. **延迟要封顶**。长列表如果每个都 +45ms，第 20 个要等 0.9 秒，
   反而显得卡。所以用 `nth-child(n+8)` 把后面的统一定在一档。

卡片列表用同样的手法：
```css
.grid .card{animation:cardIn .34s var(--ease) both}
.grid .card:nth-child(1){animation-delay:20ms}
.grid .card:nth-child(2){animation-delay:58ms}
/* … */
.grid .card:nth-child(n+7){animation-delay:240ms}
```

**多层 stagger 叠加**（区块 + 卡片）会产生「层层展开」的纵深效果。

### 4.6 脉冲提醒（需要注意的东西）

```css
@keyframes softPulse{
  0%,100%{box-shadow:0 0 0 0 rgba(194,91,80,0)}
  50%    {box-shadow:0 0 0 3px rgba(194,91,80,.13)}
}
.warn{animation:softPulse 2.4s var(--ease2) infinite}
```

**用于**：紧急标记（3 天内到期）、未读小红点、30 分钟内有课。
**周期要慢**（2 秒以上），快了会让人焦虑。

### 4.7 滚动渐隐遮罩

```css
#viewport::before,#viewport::after{
  content:"";position:absolute;left:0;right:0;height:16px;
  pointer-events:none;              /*  不能挡住鼠标事件 */
  z-index:5;
}
#viewport::before{
  top:0;
  background:linear-gradient(to bottom,
    rgba(245,241,232,.95), rgba(245,241,232,0));
}
#viewport::after{
  bottom:0;
  background:linear-gradient(to top,
    rgba(245,241,232,.95), rgba(245,241,232,0));
}
```

**作用**：内容滚到边缘时自然淡出，暗示「上面/下面还有内容」。
比加一个「更多」提示更简洁。

## 5.  折叠动画的正确做法

###  错误做法

```css
.secbody{display:none}
.sec.open .secbody{display:block}      /* 无法动画，直接一跳 */
```

用 `display` 切换**完全无法动画**（元素直接从布局里消失）。

###  正确做法：`grid-template-rows: 1fr → 0fr`

```css
.secbody{
  display:grid;
  grid-template-rows:1fr;            /* 展开：1 倍内容高度 */
  opacity:1;
  padding-top:3px;
  transition:grid-template-rows .36s var(--ease),
             opacity .28s var(--fast),
             padding-top .36s var(--ease);
}
.secinner{overflow:hidden;min-height:0}   /*  两层结构，必须的 */
.sec.collapsed .secbody{
  grid-template-rows:0fr;            /* 折叠：0 倍高度 → 高度动画到 0 */
  opacity:0;
  padding-top:0;
}
```

HTML 结构（**两层，不能省**）：
```html
<div class="sec">
  <div class="sechead" data-tg="tasks">
    <span class="arw">▾</span>
    <span class="t">全部待办</span>
    <span class="cnt">16</span>
  </div>
  <div class="secbody">
    <div class="secinner">           <!--  这层负责 overflow:hidden -->
      <!-- 真正的内容 -->
    </div>
  </div>
</div>
```

**为什么必须两层**：
`grid-template-rows:0fr` 只让**网格行**高度为 0，
里面的内容**仍然会溢出显示**。所以需要 `.secinner{overflow:hidden}`
把溢出裁掉。而 `min-height:0` 是 Grid 项目的必需项（默认 `min-height:auto`
会阻止收缩）。

**箭头旋转**：
```css
.sechead .arw{transition:transform .34s var(--spring)}
.sec.collapsed .arw{transform:rotate(-90deg)}
```
用 `--spring` 让它「弹」到位，手感更好。

## 6. 页面横滑切换

三个页签横向排列，靠 `translateX` 整体平移。

```css
#pages{
  display:flex;height:100%;
  transition:transform .42s var(--ease);
}
.page{
  min-width:100%;                    /*  每个页面占满宽度 */
  height:100%;overflow-y:auto;
  transition:transform .42s var(--ease),
             opacity .32s var(--fast);
  will-change:transform,opacity;
  overscroll-behavior-y:contain;     /* 防滚动穿透 */
}
.page.off{opacity:.5;transform:scale(.93)}   /* 非当前页：缩小 + 变暗 */
.page.on {opacity:1;  transform:scale(1)}
```

JS 切换：
```js
function switchTab(i, animate){
  curTab = i;
  const pages = document.querySelector('#pages');
  if(pages) pages.style.transform = `translateX(${-i*100}%)`;

  document.querySelectorAll('.page').forEach((el, idx)=>{
    el.classList.toggle('on',  idx === i);
    el.classList.toggle('off', idx !== i);
  });
  document.querySelectorAll('.tab').forEach(el=>{
    el.classList.toggle('active', +el.dataset.tab === i);
  });
  localStorage.setItem('mb.tab', String(i));    /* 记住位置 */
}
```

** 「纵深」是怎么出来的**：
非当前页不是简单地「看不见」，而是 `scale(.93) + opacity(.5)` ——
看起来像往后退了一层。**这比直接滑动有空间感得多。**

**三种触发方式**（都要支持，用户习惯不同）：

```js
/* ① 触屏滑动 */
vp.addEventListener('touchstart', e=>{
  sx = e.touches[0].clientX; sy = e.touches[0].clientY; dragging = true;
}, {passive:true});
vp.addEventListener('touchmove', e=>{
  if(!dragging) return;
  const dx = e.touches[0].clientX - sx;
  const dy = e.touches[0].clientY - sy;
  /*  只在「横向明显大于纵向」时才翻页，否则会和纵向滚动打架 */
  if(Math.abs(dx) > 60 && Math.abs(dx) > Math.abs(dy) * 1.6){
    dragging = false;
    if(dx < 0 && curTab < MAXTAB) switchTab(curTab + 1);
    else if(dx > 0 && curTab > 0) switchTab(curTab - 1);
  }
}, {passive:true});

/* ② 鼠标横向滚轮（触控板） */
vp.addEventListener('wheel', e=>{
  if(Math.abs(e.deltaX) > Math.abs(e.deltaY) + 8){    /*  阈值，防误触 */
    if(e.deltaX > 24 && curTab < MAXTAB) switchTab(curTab + 1);
    else if(e.deltaX < -24 && curTab > 0) switchTab(curTab - 1);
  }
}, {passive:true});

/* ③ 键盘方向键 */
document.addEventListener('keydown', e=>{
  const t = e.target;
  /*  输入框里按方向键不切页 */
  if(t && ['INPUT','TEXTAREA','SELECT'].includes(t.tagName)) return;
  if(e.key === 'ArrowRight' && curTab < 2) switchTab(curTab + 1);
  else if(e.key === 'ArrowLeft' && curTab > 0) switchTab(curTab - 1);
});
```

**Tab 指示条的弹簧展开**：
```css
.tab::after{
  content:"";position:absolute;left:12px;right:12px;bottom:-1px;height:2.5px;
  border-radius:2px;background:transparent;
  transform:scaleX(0);transform-origin:center;      /*  从中间展开 */
  transition:background .2s var(--fast),
             transform .34s var(--spring);          /*  回弹曲线 */
}
.tab.active::after{
  background:linear-gradient(90deg,var(--blue),var(--violet));
  box-shadow:0 0 8px rgba(74,127,181,.45);
  transform:scaleX(1);
}
```

## 7. SVG 图标系统

**为什么不用 emoji**（用户明确提出「不要简单用 emoji」）：

| 问题 | 说明 |
|---|---|
| 外观不一致 | 不同 Windows 版本、不同字体的 emoji 长得完全不一样 |
| 无法跟随主题色 | emoji 是彩色位图，不能改成 `currentColor` |
| 描边粗细不统一 | 混在一起显得杂乱 |
| 排版会跳 | emoji 的基线、宽度在不同环境有差异 |

**方案**：在 HTML 顶部内嵌一个 `<svg><defs>` 图标库（约 30 个 symbol）。

```html
<svg width="0" height="0" style="position:absolute;overflow:hidden">
  <defs>
    <!-- 统一 24×24 viewBox，只用 path，不写 fill（由 CSS 控制） -->
    <symbol id="i-folder" viewBox="0 0 24 24">
      <path d="M3 7.5A2.5 2.5 0 0 1 5.5 5h3.1a2 2 0 0 1 1.55.72l.9 1.06
               a2 2 0 0 0 1.55.72h6.4A2.5 2.5 0 0 1 21 10v6.5A2.5 2.5 0 0 1
               18.5 19h-13A2.5 2.5 0 0 1 3 16.5Z"/>
    </symbol>
    <symbol id="i-refresh" viewBox="0 0 24 24">
      <path d="M20.5 12a8.5 8.5 0 1 1-2.6-6.1"/>
      <path d="M20.8 4.2v4.6h-4.6"/>
    </symbol>
    <!-- … -->
  </defs>
</svg>
```

**注意 `width="0" height="0"`** —— 图标库本身不占位置，
只是个「定义容器」。真正使用时会 `<use>` 引用。

### 使用方式

```html
<svg class="oi"><use href="#i-folder"/></svg>
```

```css
.oi{
  width:15px;height:15px;display:block;flex:0 0 auto;
  fill:none;                          /*  线性风格：不填充 */
  stroke:currentColor;                /*  颜色跟随文字 */
  stroke-width:1.9;
  stroke-linecap:round;               /* 端点圆角 */
  stroke-linejoin:round;              /* 拐角圆角 */
  pointer-events:none;                /* 点击穿透到父元素 */
  transition:stroke-width .15s var(--ease);
}
/* 尺寸档位 */
.oi.lg {width:17px;height:17px;stroke-width:1.75}
.oi.sm {width:13px;height:13px;stroke-width:2.1}   /*  小图标描边要粗 */
.oi.xxl{width:36px;height:36px;stroke-width:1.35}  /*  大图标描边要细 */
/* 行内（跟文字走） */
.oi.inl{display:inline-block;vertical-align:-2.5px;margin-right:4px}
```

** 关键点**：
- `stroke:currentColor` → 图标颜色自动跟随父元素文字颜色。
  改成 `color:var(--blue)` 就能变蓝，不需要准备两套图标。
- **小图标描边要粗、大图标描边要细** ——
  否则 13px 的图标用 `stroke-width:1.9` 会糊成一团，
  而 36px 的用 1.9 又显得太笨重。

### JS 生成器

```js
function icon(name, cls){
  return `<svg class="oi ${cls||''}"><use href="#${name}"/></svg>`;
}
```

用法：`icon('i-folder', 'sm inl')`

###  最大的坑：不要用 textContent 改含 SVG 的按钮

```js
/*  错误 —— 会把里面的 <svg> 整个抹掉，图标消失 */
btn.textContent = '⟳';

/*  正确 */
btn.innerHTML = icon('i-refresh', 'sm');
```

**如果按钮状态要来回切换**，记得先把原内容存起来：

```js
const fact = el.querySelector('.fact');
const factOld = fact ? fact.innerHTML : '';        /*  先存 */
if(fact) fact.innerHTML = icon('i-refresh','sm');  /* 换成转圈 */

/* …稍后恢复 */
if(fact) fact.innerHTML = factOld;
```

## 8. GPA 圆环的描边动画

用 SVG 的 `stroke-dasharray` + `stroke-dashoffset` 做进度环。

```js
/* JS 里生成 SVG */
const R = 34;                                  /* 半径 */
const C = 2 * Math.PI * R;                     /* 周长 = 213.6 */
const frac = pc != null ? Math.min(1, Math.max(0, pc/100)) : 0;

const ring = `<svg width="92" height="92" viewBox="0 0 92 92">
  <!-- 底环（灰） -->
  <circle cx="46" cy="46" r="${R}" fill="none"
          stroke="#ede5d6" stroke-width="9"/>

  <!-- 进度环（彩色） -->
  <circle cx="46" cy="46" r="${R}" fill="none"
          stroke="${pc!=null ? pctColor(pc) : '#ddd3bf'}"
          stroke-width="9" stroke-linecap="round"
          stroke-dasharray="${C}"
          stroke-dashoffset="${C}"
          transform="rotate(-90 46 46)">     <!--  从 12 点方向开始 -->
    <animate attributeName="stroke-dashoffset"
             from="${C}"
             to="${C * (1 - frac)}"
             dur=".85s" fill="freeze"
             calcMode="spline"
             keySplines="0.22 1 0.36 1"      <!--  和 --ease 一样的曲线 -->
             keyTimes="0;1"/>
  </circle>

  <!-- 中间的文字 -->
  <text x="46" y="44" text-anchor="middle"
        font-size="22" font-weight="800"
        fill="${lv ? lvlColor(lv) : 'var(--dim)'}">${lv || '—'}</text>
  <text x="46" y="60" text-anchor="middle"
        fill="#a89e8b" font-size="9">
    ${pc != null ? pc.toFixed(2) + '%' : '未出分'}</text>
</svg>`;
```

**原理**：
- `stroke-dasharray = 周长` → 一圈都是「实线」
- `stroke-dashoffset = 周长` 时，实线整体移出去 → 看不见
- `stroke-dashoffset = 周长 × (1 - 进度)` → 显出对应比例的弧
- `rotate(-90)` 让起点从 12 点方向开始（默认在 3 点方向）
- `stroke-linecap:round` 让弧的两端是圆的，更好看
- **用 SMIL `<animate>` 而不是 CSS**：因为这里要动的是 SVG 属性，
  用 SMIL 最直接（现代浏览器都支持）

**`calcMode="spline"` + `keySplines`** 等于给 SVG 动画加缓动曲线 ——
和 CSS 的 `cubic-bezier(.22,1,.36,1)` 是同一个值，所以动效风格统一。

## 9. 图表柱子的生长动画

同样是 SMIL，但动的是 `width`。

```js
const bars = courses.map((c, i) => {
  const y = i * rowH + 3;
  const w = Math.max(2, (c.overall_percent / 100) * W);
  return `
    <text x="0" y="${y+8}" fill="#8a8171" font-size="8">
      ${esc(c.name.slice(0, 19))}</text>

    <!-- 底槽 -->
    <rect x="0" y="${y+11}" width="${W}" height="5" rx="2.5" fill="#ede5d6"/>

    <!-- 彩色柱子：从 0 长到 w -->
    <rect x="0" y="${y+11}" width="${w}" height="5" rx="2.5"
          fill="${colorOf(i)}">
      <animate attributeName="width" from="0" to="${w}"
               dur=".6s" fill="freeze"/>
    </rect>

    <text x="${W+2}" y="${y+16}" fill="${pctColor(c.overall_percent)}"
          font-size="8.5" font-weight="700">
      ${c.overall_percent.toFixed(1)}%</text>`;
}).join('');
```

**要点**：
- `rx="2.5"` 让柱子两端是圆头（`height:5` 的一半）
- `from="0"` → 从左边「长」出来，比直接出现有生命力
- 每条柱子可以加 `begin` 属性做错开：`begin="${i*0.06}s"`
  （本文这个项目没加，因为课程数少）

## 10. 骨架屏

**加载时显示「内容的轮廓」，而不是一个转圈的图标。**

```css
.skel{
  height:50px;border-radius:var(--r);margin-bottom:7px;
  background:linear-gradient(100deg,
    #f2ece0 30%, #fbf7ee 50%, #f2ece0 70%);   /*  三段，中间亮 */
  background-size:220% 100%;                   /*  背景比元素宽，才能平移 */
  animation:sh 1.25s ease-in-out infinite;
}
@keyframes sh{
  0%  {background-position:180% 0}
  100%{background-position:-80% 0}
}
```

**原理**：
- 渐变的三段 = 一条「高光带」
- `background-size:220%` 让渐变比元素宽，这样平移时高光会扫过
- 平移动画 = 高光带从右往左扫 → 「正在加载」的暗示

** 为什么不是 `/`90deg`？**
用 `100deg` 稍微倾斜一点，扫过时有「斜光」的质感，比水平扫描自然。

**JS 生成多个骨架并错开**：
```js
let sk = '';
for(let i = 0; i < 5; i++){
  sk += `<div class="fskel" style="animation-delay:${i*70}ms"></div>`;
}
```

## 11. Toast 提示的回弹

```css
#toast{
  position:fixed;left:50%;bottom:-70px;         /*  初始在屏幕外 */
  transform:translateX(-50%);
  background:#3d3830;color:#faf6ec;font-size:11.8px;
  padding:9px 15px;border-radius:11px;z-index:999;
  display:flex;align-items:center;gap:10px;
  box-shadow:0 8px 26px rgba(60,50,35,.3),
             0 2px 6px  rgba(60,50,35,.18);     /* 分层阴影 */
  transition:bottom .42s var(--spring),         /*  回弹曲线 */
             opacity .3s var(--fast);
  opacity:0;max-width:88vw;
}
#toast.show{bottom:18px;opacity:1}
```

**为什么用 `bottom` 而不是 `transform: translateY`**：
两者都能动，但 `bottom` 语义更直白，而且这里的 `transform` 已经被
`translateX(-50%)` 用于居中了 —— 混在一起会冲突。

**回弹曲线 `--spring`** 让 Toast「弹」上来，比匀速滑入更有质感。

## 12. 响应式与无障碍

### 12.1 内容自适应（不用媒体查询）

```css
#stats{
  display:grid;
  grid-template-columns:repeat(auto-fit, minmax(86px, 1fr));  /*  自适应列数 */
  gap:7px;
}
.grid{
  display:grid;gap:7px;
  grid-template-columns:repeat(auto-fill, minmax(228px, 1fr));
}
```

`auto-fit` / `auto-fill` + `minmax()` → **一行代码实现响应式**，
窗口多宽都能自动排列，不需要写断点。

### 12.2 双层焦点环（学 GitHub）

```css
:focus-visible{
  outline:2px solid var(--blue);
  outline-offset:2px;
  border-radius:6px;
  box-shadow:0 0 0 4px rgba(74,127,181,.18) !important;   /*  第二层柔和光晕 */
}
```

**用 `:focus-visible` 而不是 `:focus`** ——
前者只在**键盘操作**时触发，鼠标点击不会出现焦点环。
这样既照顾了键盘用户，鼠标用户也不会看到多余的框。

### 12.3 尊重「减少动效」设置

```css
@media (prefers-reduced-motion:reduce){
  *,*::before,*::after{
    animation-duration:.01ms !important;
    animation-iteration-count:1 !important;
    transition-duration:.01ms !important;
  }
}
```

有些用户（前庭功能障碍、或单纯不喜欢动效）会在系统里关掉动画。
**这个媒体查询必须加** —— 既是无障碍要求，也省电。

### 12.4 滚动条美化

```css
::-webkit-scrollbar{width:8px;height:8px}
::-webkit-scrollbar-thumb{
  background:#ded4c0;border-radius:9px;
  border:2px solid transparent;              /*  用透明边框做内缩 */
  background-clip:content-box;
}
::-webkit-scrollbar-thumb:hover{
  background:#cdc0a6;background-clip:content-box;
}
::-webkit-scrollbar-track{background:transparent}
```

**技巧**：`border:2px solid transparent` + `background-clip:content-box`
→ 滑块比滚动条窄，形成「悬空」的视觉效果，比实心条精致。

### 12.5 等宽数字（防抖动）

```css
.stat .n{
  font-variant-numeric: tabular-nums;    /*  数字等宽 */
}
```

倒计时、分数、GPA 这类**会变化的数字**一定要加。
否则数字从 `9` 变成 `10` 时宽度会跳，整个布局都在抖。

## 13.  怎么验证动效

**pywebview 窗口无法截图**，所以不能靠「看图」验证。用**客观检查**：

### 13.1 生成预览页

`make_preview.py` 会复制 `index.html`，
在主脚本前注入一段 mock，**拦截所有 `pywebview.api.*` 调用喂假数据**：

```python
MOCK = { "status": "ok", "courses": [...], "tasks": [...] }

mock_js = f"""
<script>
const MOCK = {json.dumps(MOCK, ensure_ascii=False)};
window.pywebview = {{
  api: {{
    get_data: () => Promise.resolve(MOCK),
    files_list: () => Promise.resolve(MOCK_FILES),
    /* …全部接口 */
  }}
}};
</script>
"""

# 插到主脚本之前
marker = "<script>\nconst $ = s => document.querySelector(s);"
out = src.replace(marker, mock_js + marker, 1)
```

**为什么不用 `?mock=1` 参数**：注入是**独立文件**，
所以 `index.html` 里一行 mock 代码都不需要，生产代码保持干净。

## 14. 常见错误清单

###  1. CSS 变量自我引用

```css
--ease: var(--ease);        /* 静默失效，全部动效变硬切 */
```

###  2. 用 `display` 做展开动画

```css
.secbody{display:none}
.open .secbody{display:block}   /* 无法动画 */
```
→ 改用 `grid-template-rows: 1fr → 0fr`

###  3. `textContent` 覆盖含 SVG 的按钮

```js
btn.textContent = '⟳';          /* SVG 图标被抹掉 */
```
→ 用 `btn.innerHTML = icon('i-refresh','sm')`

###  4. stagger 延迟不封顶

```css
.card:nth-child(20){animation-delay:900ms}   /* 等太久，反而像卡了 */
```
→ 用 `nth-child(n+7){animation-delay:240ms}` 封顶

###  5. 忘记 `animation-fill-mode: both`

```css
.sec{animation:riseIn .38s var(--ease)}      /* 动画开始前会闪一下 */
.sec{animation:riseIn .38s var(--ease) both} /*  */
```

###  6. 会变的数字没用等宽

```css
.countdown{font-variant-numeric:tabular-nums}   /* 必须加 */
```

###  7. 忘记 `pointer-events:none` 给装饰性遮罩

```css
#viewport::before{pointer-events:none}   /* 否则挡住下面的点击 */
```

###  8. 滚动穿透

```css
.page{overscroll-behavior-y:contain}     /* 防止滚动影响父容器 */
```

###  9. 横滑和纵滚打架

```js
/* 必须判断「横向明显大于纵向」才翻页 */
if(Math.abs(dx) > 60 && Math.abs(dx) > Math.abs(dy) * 1.6) { ... }
```

###  10. 忘记 `prefers-reduced-motion`

无障碍要求，也是省电手段。

###  11. EMOJI 在不同环境下长得不一样

→ 用 SVG symbol 库

###  12. 小图标用大描边、大图标用小描边（反了）

```css
.oi.sm {stroke-width:2.1}    /* 小 → 粗 */
.oi.xxl{stroke-width:1.35}   /* 大 → 细 */
```

##  三条最重要的心得

1. **动效的价值在「暗示结构」，不在「炫技」**。
   卡片浮起 = 可点击；内容淡出 = 还有更多；
   背景变暗 = 这一层不重要。**每个动效都该回答一个「这是什么东西」。**

2. **越快的地方越要快**。
   按钮反馈 80ms、卡片悬停 160ms、入场 340ms、页面切换 420ms。
   小元素用长时长会显得「黏」。

3. **统一的曲线比多样的曲线更高级**。
   全站只用 4 条曲线，且含义明确（默认 / 标准 / 快速 / 回弹）。
   到处用不同的 `ease-in-out` 反而显得乱。
